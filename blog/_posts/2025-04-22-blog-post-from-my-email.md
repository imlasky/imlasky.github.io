If you’re reading this then I have successfully hooked up my email to my blog, so now I can just write an email and a new blog post will appear on my blog!

I’m going to use it for a while before doing a proper write up, but the long and short of it is that I used[val.town's](https://val.town) email val functionality to get an email address I can send something to and run code when it comes in. Then the code executes to turn my email (subject is the title, body is the content, in markdown) into a post and then pushes to my GitHub repo with an update. Overall, was able to do in a couple hours!

I think this will help me do it more on-the-go without needing to be in front of my computer.
